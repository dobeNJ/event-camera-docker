The Prophesee viewer source is located at:
/usr/share/prophesee_driver/samples/prophesee_viewer/prophesee_viewer.cpp


In the original code, recording is triggered by camera.start_recording(filename_to_log_into) and stopped with camera.stop_recording(), both called on SPACE key press — making it impossible to control programmatically.

Modification: The file is patched to listen for UNIX signals instead: SIGUSR1 starts recording and SIGUSR2 stops it. The patched file is saved as prophesee_viewer_patched.cpp in /prophesee_viewer_modif/

Copy the patched file into the container:

docker cp /home/doha/prophesee_viewer_modif/prophesee_viewer_patched.cpp   test2:/usr/share/prophesee_driver/samples/prophesee_viewer/prophesee_viewer.cpp


Install build dependencies inside the container (required once — the container did not have CMake or Boost binary libraries pre-installed):

docker exec -it --user root test2 bash -c "
  apt-get update &&
  apt-get install -y cmake build-essential \
    libboost-system-dev libboost-filesystem-dev
"

Build inside the container:
docker exec -it test2 bash -c "
  cd /usr/share/prophesee_driver/samples/prophesee_viewer &&
  rm -rf build &&
  mkdir -p build && cd build &&
  cmake .. && make -j\$(nproc)
"

Then exect the file to record the event and move the motor : 
the file is inside : /prophesee_3axis_cinetics , names 'record_motor_sync.py'

Run the synchronized acquisition (from the host, outside Docker):
python3 /prophesee_3axis_cinetics/record_motor_sync.py --launch-viewer

After the exec , to kill the camera : 
docker exec test2 pkill -f prophesee_viewer

This script starts the patched viewer inside the container (test2), sends SIGUSR1 to begin recording, simultaneously commands the motor via serial (/dev/ttyACM0), monitors motor status until it completes the full go-and-return movement, then sends SIGUSR2 to stop recording. Speed, duration, and pulse positions are saved in a metadata_*.json alongside the .raw file.

Stop the camera after recording:

docker exec test2 pkill -f prophesee_viewer
